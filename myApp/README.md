# NeuroSafe Mobile

Expo Go MVP для хакатона: инклюзивное приложение для нейроотличных пользователей, которое строит более спокойные маршруты с учётом шума, толпы и сенсорной нагрузки.

## Что уже есть

- безопасный маршрут с режимами `Быстрый`, `Самый тихий`, `Спокойный`, `Короткий`, `Доступный`
- карта с тихими зонами и шумовыми точками
- экран сенсорного профиля и родительской аналитики
- SOS и невербальная коммуникация
- вкладка зрения для слабовидящих пользователей
- Expo Router и готовый запуск через Expo Go

## Запуск

```bash
npm install
npx expo start
```

Дальше:

- открой `Expo Go` на телефоне
- отсканируй QR-код
- нажми `a`, `i` или `w`, если нужен Android / iOS / web

## Технологии

- Expo
- React Native
- Expo Router
- TypeScript
- react-native-maps

## Важно

Проект использует mock-данные и демонстрирует хакатонный MVP. Интеграции с реальными часами, биометрией, 112 и backend-аналитикой пока представлены на уровне UX-сценария.
